# Notes

One note per subject. A note is an idea, an outline, meeting notes, a draft or something else (`note_type`), and links to at least one project, Key Element or topic. A **document** is a note with a file attached; the file lives in `10 Files/Documents/`. What someone else made is a source in `06 Sources`.

Three subfolders are filled for you: `Meetings/` (meeting notes), `Highlights/` (your PDF highlights, from ICOR PDF Annotation) and `ICOR Journey Notes/` (your reflections from myICOR, synced by ICOR Connect).
