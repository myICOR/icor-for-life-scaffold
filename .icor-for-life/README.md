# .icor-for-life

Machine files for this computer. You never need to open it. It is hidden, so Obsidian does not show it and Obsidian Sync does not copy it: what lives here belongs to one device.

| Path | What it is |
| --- | --- |
| `VERSION`, `CHANGELOG.md`, `manifest.json` | which version of ICOR for Life this is |
| `.env` | API keys some plugins use (Planner, Connect, AI Chat). Never shared, never synced |
| `<plugin-id>/`, `scripts/` | files the plugins and scripts write for each other on this computer |

The structure, templates, skills and tools are in `_System/`, which every device gets.
