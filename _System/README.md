# _System

What makes this folder work, for you, your AI and the plugins. It is a normal folder so that every device gets it (Obsidian Sync skips hidden folders).

| Path | What it is |
| --- | --- |
| `schema.json` | the structure: every type of note, its folder, fields, allowed values and the types its links point to |
| `Templates/` | one template per type (Obsidian's Templates uses this folder) |
| `Tools/` | the scripts the skills call (Python 3.9+, no packages) |

Change the structure in `schema.json` first.
