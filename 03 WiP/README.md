# 03 WiP

Work in progress. Pick the first bucket that fits:

1. `Workstreams/<Name>/` for one run of something that repeats (a weekly review, a weekly video)
2. `Projects/<Project>/` for work that serves a project in `04 Inner World/My Life/Projects/`
3. `Operations/` for everything else

Inside the bucket, date the work: `YYYY-MM-DD-<slug>.md`, or a folder when it is more than one file. When it is done, what you learned goes to `04 Inner World` and the work moves to `_archive/`.
